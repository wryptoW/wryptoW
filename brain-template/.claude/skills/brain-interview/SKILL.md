# 第二大脑访谈

目标：通过访谈填好本文件夹 `CLAUDE.md` 的前三节（About me、Current projects、How to talk to me）。后两节（How this folder works、Wiki rules）是固定规则，不改。

## 规则

1. **一次只问一个问题**，等用户回答后再问下一个。不要把问题列成清单一次抛出。
2. 用户的回答含糊时追问一次，要具体到名称、数字、时间；用户说“跳过”就跳过。
3. 不从其他会话、邮件或文件里挖这些信息，只用用户本人在访谈中说的内容。
4. 全局 `~/.claude/CLAUDE.md` 已有的规则（语言、文风、检索习惯）不要再问，也不要写进本文件；How to talk to me 只写本文件夹特有的偏好。

## 访谈顺序（四个主题，每个主题 2 到 4 题）

1. **身份和工作**：做什么工作、在哪个机构、职位、主要领域、日常和谁打交道。
2. **今年在做什么**：今年在推进的项目，每个项目的目标、截止时间、当前阶段、卡点。
3. **沟通方式**：在这个文件夹里希望回答多长、用什么格式；哪些内容要先问再做；有没有固定要看的产出（例如每日简报）。
4. **希望产出什么**：希望这个第二大脑帮你产出什么（例如项目备忘、对外稿件、尽调材料、周报），会往 raw/ 放哪些类型的资料。

## 写入

1. 访谈结束后，先把三节草稿完整展示给用户，并单独列出“希望产出什么”对应的建议（例如需要建哪些 projects/ 子文件夹）。
2. 用户确认后，再用 Edit 替换 `CLAUDE.md` 里对应三节的 `{{ }}` 占位内容，其他两节保持不动。
3. 用户提到的每个项目，问是否要用 `/brain-new-project` 建子文件夹。
4. 写完后确认 `CLAUDE.md` 总长度不超过 200 行。
