# wiki 每周只读检查

**本检查只读 wiki/ 和 raw/，唯一允许写入的文件是 `output/weekly-check-YYYY-MM-DD.md`。** 不修改任何 wiki 页面，不修改 CLAUDE.md，不导入 raw/。

## 检查项

1. **矛盾**：不同页面对同一事实（数字、日期、人名、结论）说法不一致，且没有用 `## 存在分歧` 标出来的。列出两处原文和页面。
2. **孤立页面**：没有任何其他页面链接到它的页面（index.md 的链接不算）。
3. **断链**：`[[...]]` 指向不存在的页面。
4. **缺页的概念**：在 3 个以上页面被提到、但没有独立页面的概念、人物、机构。
5. **无来源说法**：事实性说法没有标 `[[sources/...]]` 的段落，按页面列出前若干处。
6. **index 不一致**：wiki/ 中存在但 index.md 没列的页面；index.md 列了但文件不存在的页面。
7. **导入积压**：raw/ 中不在 `_ingest-log.md` 里的文件数量和清单；导入记录里备注“未能读取”的文件。
8. **过期页面**：`updated` 超过 90 天、且其所属项目仍在 CLAUDE.md 的 Current projects 里的页面。

## 报告格式

写入 `output/weekly-check-YYYY-MM-DD.md`：

```
# wiki 每周检查 YYYY-MM-DD

## 概况
页面总数 N，本周新增 N，本周修改 N，raw 未处理 N。

## 需要处理（按优先级）
1. ……（问题、所在页面、建议做法）

## 各项明细
### 矛盾 / 孤立页面 / 断链 / 缺页的概念 / 无来源说法 / index 不一致 / 导入积压 / 过期页面
```

每一项都要写，没有问题就写“无”。建议做法只写建议，不执行。
